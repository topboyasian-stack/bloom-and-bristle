# Bloom & Bristle

A Nigeria-based marketplace front end built around product discovery. Shoppers move from searching and category browsing to contacting the store.

**Live site:** https://bloommarketplace.netlify.app/

![Screenshot](docs/screenshot.png)

## What I built
- Searchable product catalogue
- Category system and shop navigation
- A clear path from browsing to contacting the store
- Responsive layout for mobile and desktop
